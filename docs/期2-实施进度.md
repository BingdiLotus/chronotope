### 1. 时间旅行（`6a3b378` + 文档 `81832dc`）

**范围**：

- api：POST/GET `/sessions/{id}/checkpoints`、POST `/sessions/{id}/fork`、POST `/sessions/{id}/rollback`、GET `/sessions/{id}/diff?against=`

**验收**：store 集成测试（checkpoint 落库/水位/fork 前缀/diff 差集/rollback 截断）；api 四端点单测；e2e w10-timetravel 8 项（快照含卷 ref 非空 → 续写 → fork 分支时间轴仅首轮 completed → diff 差集 → rollback 审计事件 + 回退后继续跑）；demo 新增阶段 15（16/16）；GitHub CI 绿。

### 2. 工作区 blob 合同（`9c5c1e2` 等 4 提交）

**范围**：workspace_files 索引（migrations/013，path→sha256 内容寻址）；BlobStore（minio-go，org/blobs/{hash} 对象键——org 级 dedup，PUT 幂等）；write_file 后增量同步（索引 upsert + file_sync_state）；CreateSandbox 的 blob: 前缀恢复（从索引拉取写回）；ensureSandbox 无快照有索引 → blob: 触发；RustFS S3 凭证（RUSTFS_ACCESS_KEY/SECRET_KEY——MINIO_ROOT_* 仅 admin 面板）。

**验收**：单测（BlobStore 幂等/dedup/恢复、索引 upsert、TestWriteFileSandboxRecovery）；e2e w11-blob 4/4（写→索引→销毁→恢复读内容）；本地直测恢复链实证（销毁→blob: 恢复→读回「blob合同内容」）；GitHub CI 绿。

**过程修复**（blob e2e 实证的 5 个缺口）：bash/代码工具走恢复链（曾只覆盖文件工具）、executor destroyed/容器缺失统一 404 哨兵、execute 409→哨兵映射、**api ingress 独立于请求 ctx（durable 语义——客户端断开不得半死 invocation）**、main.go blob 初始化块补提交（漏 add 实证）。

**已知问题（已闭环）**：worker 侧 blob: 恢复链挂起——**根因**（SDK 源码级研究 + 实证）：restate-sdk-go v1.1.0 设计语义——Run 闭包返回 non-terminal 错误 → RetryableFailure + 默认 Infinite 重试策略 → 不发 Run 完成通知（sys_journal 实证 Command 无 Notification）→ invocation 无限 backing-off（确定性 404 每次重放复现）。**修复**：Run 闭包错误统一 `ToTerminalError(..., WithErrorCode(404))`（terminal 失败 journal 化，错误返回 handler，重放不重执行闭包）+ recovery 按 code 404 识别哨兵。e2e w11-blob 恢复真实 run 链路 5/5。
