## 已落地记录

### 1. 时间旅行（`6a3b378` + 文档 `81832dc`）

**范围**：
- checkpoints 表（seq 时间指针 + snapshot_ref 空间快照 + 消息投影水位）+ sessions 分支血缘列（forked_from_session/forked_at_seq）；事件 `session.checkpoint` / `session.rolled_back` / `session.forked`（migrations/012）
- store：Checkpoint CRUD（水位库内计算）、ForkSession（写时复制：事件/消息前缀 + 血缘，分支历史 dedupe 置空）、RollbackSession（投影截断 + 审计事件——事件轴真相不可变）、DiffSessions（公共前缀 + 各自后缀）
- session_ops.CreateCheckpoint：事件水位 + executor 快照（含卷）→ 时空坐标；Executor 接口补 Snapshot
- api：POST/GET `/sessions/{id}/checkpoints`、POST `/sessions/{id}/fork`、POST `/sessions/{id}/rollback`、GET `/sessions/{id}/diff?against=`

**验收**：store 集成测试（checkpoint 落库/水位/fork 前缀/diff 差集/rollback 截断）；api 四端点单测；e2e w10-timetravel 8 项（快照含卷 ref 非空 → 续写 → fork 分支时间轴仅首轮 completed → diff 差集 → rollback 审计事件 + 回退后继续跑）；demo 新增阶段 15（16/16）；GitHub CI 绿。

**过程修复的缺陷**（3 项，均有实证）：
1. 004 消息去重索引缺 session 维度（两会话同内容互斥静默丢消息）
2. executor 快照响应字段名不匹配（`snapshot_ref` vs 客户端 `ref`）——checkpoint 空间面静默丢失
3. chi 路由 shadow（时间旅行路由挂主 router 被 /sessions/{id} 子树遮蔽）

**后置标注**：控制台分支 UI（= 本表 #4）；fork 的空间面懒恢复（fork 会话从 checkpoint 快照恢复沙箱——需 executor 侧接线，并入 #2 blob 合同一起做）。
