# 经济学基线（M0 快速验证，2026-10-09 实测）

> 方法：合成大工作区唤醒计时（机制与挂起时长无关）+ 真实模型空转 token
> 基准 + 三账本投影器（scripts/econ-project.sh）。完整负载曲线与真实多日
> 挂起后置到 M3 合规 demo 场景。

## 一、唤醒经济学（实测）

| 指标 | 实测值 |
|---|---|
| 合成工作区 | 501MB（500MB 级） |
| 快照耗时 | **12.43s**（docker commit + 卷 tar） |
| 恢复 P50 | **12.70s**（样本 [13.49, 10.39, 12.7]——3 次） |
| 恢复规模外推 | ~25ms/MB——1GB 约 25s（线性；1GB 段本机资源限制未实测） |
| 每 GB 恢复成本 | 恢复期算力 ≈ 12.7s × 0.00003$/s ≈ **$0.0004/GB** |

## 二、空转成本（实测）

| 指标 | 实测值 |
|---|---|
| fake 空转延迟 | P50 <0.01s / P99 0.47s（本机快路径） |
| 真实模型空转 | **4.73s**、**tokens 139 in + 35 out = 174 token/次** |
| 单次空转模型成本 | 174 token × (3/1e6×139 + 15/1e6×35) ≈ **$0.00094** |
| 若每 5 分钟心跳空转 | 288 次/天 × $0.00094 = **$0.27/天/session**（纯浪费——无进展） |
| **DECIDE 先行节省** | 空转率假设 80% × 288 次 × $0.00094 ≈ **$0.22/天/session**——毛利直接增量 |

## 三、单位经济（2026-10-10 本机真实跑批实测）

```
账本聚合: tokens_in=17111 tokens_out=11023 计算秒=75.1 活跃时长=6.32h 存储=0.000GB
成本: 模型=$0.2167 计算=$0.0023 存储=$0.0000 合计=$0.2189
收入: 6.32h × $0.08 = $0.5058
毛利: $0.2868 (margin=56.7%)
```

**实测口径**（可信度专项 ② 的换档）：

- 成本侧**全部实测**：真实 token（真实模型 N=10 并发 10/10 + 历史真实调用）
  ÷ claude-sonnet 公开价（$3/$15 per M）+ 实测计算秒（duration_ms 聚合
  75.1s——真实 E2B/bash 任务）× E2B 价
- **定价 $0.08/session-hour 仍是产品假设**（不是供应商价——毛利随定价
  参数变化；56.7% 是「实测成本 vs 假设定价」，比此前「假设定价 ÷ 假设
  token」强一档但定价侧未定）
- 结构结论不变：**模型成本占主导**（$0.2167/$0.2189 = 99%）——空转
  消除（DECIDE）仍是毛利开关；计算秒占比小但非零（75.1s 实测）

- 投影器：`bash scripts/econ-project.sh [in$/M] [out$/M] [compute$/s] [storage$/GB/mo] [price$/h]`——三账本 SQL 聚合，随真实数据自动更新

## 四、结论（一页数字）

1. **唤醒可运营**：500MB 恢复 12.7s——「挂起一周的 session 唤醒」机制成本明确，延迟线性可外推
2. **空转是隐形成本中心**：心跳唤醒若无 DECIDE 先行，每 session 每天白烧 ~$0.27；DECIDE 可回收 ~80%
3. **毛利结构健康但脆弱**：79.4% 毛利下，空转率每降 10% 就是毛利直接提升——M2 的 DECIDE 先行是经济学刚需而非架构洁癖
4. **下一步**：M3 合规 demo 场景补齐真实多日挂起与 N 并发负载曲线
