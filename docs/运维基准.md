# 运维基准参照（2026-10 实测）

> 用途：全栈演练的过程指标快照——后续版本/环境变更时的对比基线（不是 SLO，
> 是「本机 + 官方云」组合下的参照值）。采集方式：15s 间隔 `docker stats`
> 采样 + 脚本计时；场景：真实 E2B 演练 + 真实模型 e2e 九组。

## 演练结论

| 演练 | 结果 | 耗时 |
|---|---|---|
| **E2B 官方云 smoke**（确定性 fake 脚本：bash + write_file + read_file 三工具链） | **2/2 ✅** | **14s** |
| **真实模型 e2e 九组**（36 断言） | **9/9 ✅**（real-model 组首跑受 worker 阈值默认值影响，`CONSOLIDATE_THRESHOLD=4` 后单组重跑 4/4——记录见「注意」） | **8 组 482s** + real-model 单组重跑 |

## E2B 官方云指标（真机）

| 指标 | 值 |
|---|---|
| 沙箱创建（官方云 base 模板） | 秒级（创建即 ready——`sandboxID` 立即可用） |
| 命令执行（ConnectRPC Start 端到端） | 秒级（echo/write/read 三工具链 14s 内完成） |
| 端到端 run（api → worker → executor → E2B 云） | < 15s |

## 真实 e2e 宿主资源峰值（15s 采样，118 点）

| 容器 | CPU 峰值 | 内存 |
|---|---|---|
| harness | **47.6%** | 78 MiB |
| restate | 28.3% | **1.0 GiB** |
| postgres | 5.6% | 38 MiB |
| executor | 4.4% | 6 MiB |
| worker | 3.6% | 21 MiB |
| api | 1.2% | 30 MiB |

**观察**：restate 是内存大户（1 GiB——JVM/引擎常态）；harness 的 CPU 峰值在
真实模型流式转发段（47.6%——LiteLLM 代理的流式拷贝）。

## 生产形态比较基准（真实模型 + E2B 沙箱——全生产形态，2026-10）

| 维度 | docker 档（本地） | **E2B 官方云档（生产）** |
|---|---|---|
| 真实 e2e 九组 | 9/9（482s） | **5/9 首跑（183s）+ 单组重跑**——非确定组（消化/知识引用）与 docker 档同源 |
| 单组速度 | 慢（本地沙箱冷启动秒级+） | **快**（云沙箱创建秒级——总耗时 183s vs 482s） |
| 沙箱快照恢复 | ✅ 本地卷快照 | ⚠️ **能力差异**：官方云 fork-snapshot 端点未对接（快照恢复断言失败——后置） |
| 模板 | 镜像名直用 | ✅ **E2B_TEMPLATE_MAP 映射**（`{"*":"base"}`——官方云无 python/golang 模板，「template 'python' not found」实证） |
| 命令执行 | exec 协议 | ConnectRPC（envd——已对接） |

**E2B 档生产化待办**：① 官方云 fork-snapshot 对接（快照恢复）；② 真实模型
空参 tool_call 的防御（127 实证——平台侧应报清晰错误而非执行 `{}`）；
③ filesystem 走 ConnectRPC filesystem 服务（当前命令 cat/base64 兜底）。

## 运维注意事项（演练实证）

1. **真实 e2e 前置**：worker 须 `CONSOLIDATE_THRESHOLD=4`（消化触发断言）、
   api 须 `ARCHIVE_MIN_AGE=0s`（归档断言）——compose 默认 40/24h 会让
   real-model 消化与归档断言失败（组级配置，非平台缺陷）。
2. **真实模型非确定性**：偶发「final 空 + truncated」——单组重跑即过；
   fake 绿真实红纪律：断言失败先重跑单组再判定缺陷。
3. **E2B 官方云**：命令执行走 ConnectRPC（envd）——网络出口需可达
   `api.e2b.dev` + `sandbox.e2b.app`；凭证在 `.env` 的 `E2B_API_KEY`。
4. **演练顺序**：E2B smoke 需 executor `EXECUTOR_DRIVER=e2b_selfhosted`；
   真实 e2e 的沙箱组需 docker 档——同栈切换用
   `EXECUTOR_DRIVER=... docker compose up -d --force-recreate executor`。
